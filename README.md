## Project Highlights

- Automated end-to-end workflow orchestration using n8n.
- RSS data ingestion and JavaScript-based processing.
- AI-assisted competitor intelligence analysis.
- Structured report generation with evidence limitations.
- Automated HTML email delivery through Gmail.
